What's real here, and what isn't

  • Views and likes are real — genuine clicks, stored on a server, shared across everyone.
  • The trend line is built on this device. Each time you open this page it saves a snapshot, so the chart only covers times you've actually looked. Open it on a different browser and that chart starts empty.
  • The "people viewing right now" pill on the public site is simulated. It's random numbers and is not counted anywhere here.
  • Counters can be nudged. They're public URLs, so a determined person could inflate a number.
  • For real privacy and true timestamps, finish the GoatCounter setup in js/analytics.js. That dashboard sits behind your login and records exactly when each visit happened.
